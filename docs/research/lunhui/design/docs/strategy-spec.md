# 策略规格：把《轮回》变成可证伪的交易计划

本文件为待实施、待验证的研究规格，无已完成回测。段落见 [extracted.txt](../references/lunhui/extracted.txt)。**原文经验、观测代理、工程裁决分开记录。** 参数在训练区间选择后冻结，不能见走势后改动。

首版研究 `S01` 主线核心分歧修复、`S02` 新方向确认，先回放再模拟。退潮退出与 `WAIT` 为通用管理。范围依 [系统设计](system-design.md)：沪深主板非风险警示普通A股、无杠杆做多、连续竞价限价单；竞价只观察。

## 1. 原文、观测与假设分开

| 层 | 原文与出处 | 观测代理及限制 |
|---|---|---|
| 环境 | 指数、流动性、生态影响策略；P1651–P1703 | 多指数、广度、同刻成交额、生态收益与尾部损失；技术背离效力尚未证明 |
| 情绪 | 赚钱/亏钱效应、连板高度、两类冰点；P0020–P0045、P0454、P0532 | 冻结强势组合收益、负尾部、晋级与炸板比例；不认定“4板以下退潮结束” |
| 题材 | 启动到退潮有不同演变路径；P0186–P0308、P0337–P0363 | 时点成分广度、收益、成交占比和梯队；不以最终二波反证事前题材大 |
| 个股 | 地位、主动性、抗跌与逻辑；P0665–P0689、P1275–P1277 | 相对强弱、顺位、回撤、同组响应、业务证据；时序领先不等于因果 |
| 预期/纪律 | 计划交易、模式外空仓、预期差；P0011–P0012、P1634–P1643 | 冻结计划与事实比较；不把“满仓”“体面离场”写成交易保证 |

市场状态为 `UNKNOWN / CHAOS / IGNITION / EXPANSION / CLIMAX / RETREAT / REPAIR`，与题材/个股分开，由版本规则提出并保留反证，不强制顺序循环。龙头是时点假设 `leader_candidate`，不同角色可并存（P0659–P0663、P0706–P0710），事后赢家不回写候选。

## 2. 两个策略共享的观测与门槛

### 2.1 观测时钟与基础量

首版在完整分钟结束后计算信号，最早委托在信号可用之后。不能由同根分钟线推断路径或保证收盘价成交；下单另核最新报价。仅有日线无法评估以下策略。

| 符号/谓词 | 客观定义 |
|---|---|
| `U_theme` | 冻结成员、依据及可用时间；新增开修订，不回填历史。 |
| `r_i(t,a)` | 从登记锚点 `a` 到 `t` 的收益，使用时点规则；不事后选低点。 |
| `breadth(t)` | 上涨数 / 合格且有观测的成员数；另报停牌、缺失和负尾部，排除候选自身。 |
| `theme_return(t)` | 冻结题材篮子的等权收益；权重和锚点版本化。比较时排除自身。 |
| `rs_i(t)` | `r_i(t,a) - theme_return_without_i(t,a)`；同时报告相对市场收益，不择优选基准。 |
| `volume_ratio(t)` | 累计成交额 / 过去 `L` 日同刻累计成交额中位数；分母零则不可评估。 |
| `loss_rate(t)` | 昨日冻结强势组合中低于负尾部阈值者占比；不可交易和缺失项单列。 |
| `DataOK` | 时点、鲜度、样本、覆盖率合格且无来源冲突；缺失为 `NOT_EVALUABLE`。 |
| `MarketOK(S)` | 当前市场状态在策略允许集合，状态确认窗口满足，无强冲突和系统性风险否决。 |
| `ExecutionEligible` | 证券/阶段获授权，双边报价、价差、深度达标；封死涨停、停牌不满足。 |

入场要求 `DataOK AND MarketOK(S) AND ExecutionEligible AND PlanValid`。后者要求计划早于观测窗、未过期且无否决证据。通过后仅可 `PROPOSE`，数量由独立风控确定。

### 2.2 预期卡和参数约束

`ExpectationPlan` 冻结版本、候选/题材、锚点、状态、触发/否决、窗口、价格区间、持有期及“符合/强于/弱于预期”分支（P1426、P1634–P1643）。修订仅影响之后窗口。

参数台账登记回看窗 `L`、成员下限 `N_min`、覆盖率、价差/深度、回撤 `d`、确认长度 `k`、缓冲 `b`、广度改善 `ΔB`、相对强度 `s`、量能区间、负尾部上限 `q`、有效期 `τ`、失效价及持有期 `H`，注明单位、时段、训练窗与敏感性。

本轮不设未经验证的生产值，参数版本不完整则不可评估。原文情绪1500/3500、封单8/10/15亿、竞昨成比5/15/20%等仅为研究候选（P0094、P0130、P0203–P0204、P0455–P0457、P0802、P0874、P0888）。`880005`与“情绪值”口径不完整，首版不依赖。

## 3. S01：主线核心分歧修复

**假设**：主线分歧后，核心地位保留、题材恢复且市场亏钱未扩散时，成本后表现可能优于仅看股价反弹。依据：P0243–P0265、P0292–P0308、P0780–P0784、P0901–P0902、P1639–P1642。

### 状态和候选门槛

- 市场允许 `REPAIR / EXPANSION`；`RETREAT / CLIMAX / UNKNOWN` 禁止新增，`CHAOS / IGNITION` 尚不适用本策略。
- 题材在此前窗口的广度、相对收益与成交参与已通过主线门槛，不能因当前上涨补授地位。
- 个股在分歧前已入候选集合且达到地位门槛，不能补入事后涨幅第一名。
- 题材未证伪，核心与补涨未共振恶化，市场负尾部未持续扩大（P0265、P0378）。

### 事件序列与联合触发

1. **登记分歧 `D`**：预登记窗内核心从已发生高点回撤至少 `d_i`，且题材广度下降至少 `d_B`、或篮子回撤至少 `d_T`；逻辑组合在版本中固定。仅单票下跌不算题材分歧。
2. **冻结观察锚点**：识别 `D` 后冻结当时低点 `L0`、失效边界及参考价规则 `R`。`R` 事先选择开盘价/前收/因果 VWAP 之一，不能反弹后换锚；VWAP 仅用当时数据。
3. **等待确认 `C`**：随后完整 `k` 分钟不破 `L0` 缓冲，重回并保持 `R` 上方，`rs_i >= s`，广度比 `D` 改善至少 `ΔB`，篮子收益改善、负尾部不扩大；题材指标排除自身。
4. **检查成交与预期**：量能、价差/深度达标并满足冻结修复分支；单根拉升不够。超过价格上沿或 `τ` 即过期，不追价。
5. **生成提案**：全部通过才 `PROPOSE` 并附实测值与反证；仍在确认窗则 `WATCH`，缺失/冲突/失效则 `WAIT`。

跌破边界即关闭本次尝试，不得下移 `L0` 延续故事。新事件间隔和当日尝试上限需预登记。

### 失效与退出

市场退潮、广度恶化、核心地位丢失、逻辑证伪或价格越界即令提案失效。持仓按入场前的价格线、假设失效、期限 `H` 和组合风险触发 `REDUCE / EXIT`；不得将失败修复改名长期格局。不可卖按通用管理记录。

### 数据和待验证参数

需要时点题材映射、分歧前候选、分钟行情、同刻量能基线、报价、强势组合、公告和账户状态。检验 `d_i/d_B/d_T`、`k`、`ΔB`、`s`、量能、`H`及重试限制，不依赖对主力身份的猜测。

**不是见涨就算修复**：先有登记分歧，再有独立确认、核心地位与排除自身的题材改善。只有核心反弹、后排继续崩溃则失败；没有先前计划，涨了也不算本策略识别。

## 4. S02：旧线退潮后的新方向确认

**假设**：旧线负反馈中，有公开独立催化的新方向形成持续、跨个股、可交易响应，可能出现切换机会。依据：P0186–P0196、P0401–P0403、P0672–P0675、P0855–P0860、P1333–P1343、P1405–P1426。

### 状态和候选门槛

- 市场允许 `CHAOS / IGNITION / REPAIR / EXPANSION`，禁止 `RETREAT / CLIMAX / UNKNOWN` 新增。**旧题材退潮不等于全市场退潮**；系统性亏钱仍在扩散时不靠“新方向”豁免。
- 旧线此前已入计划，广度、核心与篮子连续满足退化条件，登记 `old_theme_retreat`；单只旧龙断板不够。
- 新方向有决策前公开可核验的催化/经营证据；名称、代码、字辈、旧线补涨不算独立催化，证据不足仅研究。
- 候选在观察窗开始前入池。盘中新发现先建修订，再观察之后窗口，不用此前拉升补足确认。

### 事件序列与联合触发

1. **证据确认 `E`**：建立催化原文、`available_at`、受益链及公司关联；谣言、无出处小表格或模型自行生成关系不满足。
2. **广度确认 `B`**：篮子达到成员下限，排除自身后的广度、相对收益和同刻成交额满足 `k_new` 个完整观测；单票涨停不够。
3. **持续与参与确认 `P`**：负尾部未超限，候选相对地位、报价与成交持续性达标；全板块一字买不到，不改买任意后排。
4. **切换而非共振下跌检查 `R`**：市场 `loss_rate` 未超限，旧线负反馈未系统扩散，新线相对强度保持；负相关不证明资金来源。
5. **计划匹配**：`E AND B AND P AND R` 加共享门槛全过、价格/时间未越界才 `PROPOSE`；否则 `WATCH / WAIT`。

不抢竞价或首板，不以后续三四板反证首日新周期；确认长度待检验（P0187）。

### 失效与退出

催化辟谣、业务关系不成立、广度持续衰退、核心地位丢失、新旧线同步恶化或市场进入禁止状态，触发提案失效及退出评估。持有期和失效价预先登记；孤立上涨不升级“真龙”以延期。

### 数据和待验证参数

需要催化及可用时点、题材关系、旧线事件、分钟行情、市场广度/负尾部与报价。研究旧线退化阈值/窗口、`N_min`、`k_new`、篮子收益/广度/量能、催化有效期、价格区间和 `H`。

**不是见涨就算新主线**：独立证据、多股响应、持续确认和风险约束必须齐备；最强单票、短时负相关或传闻不足以完成 `E/B/P/R`。

## 5. 通用管理：WAIT、退潮退出与风险优先

| 条件 | 新增风险 | 已有风险 | 依据 |
|---|---|---|---|
| 未匹配、数据缺失/冲突 | `WAIT`；有效确认窗内可 `WATCH` | 执行原管理计划 | P0011–P0012 |
| 市场退潮、普遍严重不及预期 | 停止新增，取消失效提案 | 按预登记政策 `REDUCE / EXIT` | P0302、P0440–P0441、P1287–P1292 |
| 题材证伪、核心地位丢失 | 取消相关提案 | 假设失效退出，检查关联暴露 | P0013、P0378、P1261–P1263 |
| 价格线、期限或风险预算触发 | 不摊低成本 | 确定性管理，不等模型批准 | 工程裁决 |
| 无可卖量、跌停无承接、订单未知 | 禁止新增相关风险 | 记录退出受阻、残余暴露和恢复条件 | P0992–P0993及执行规则 |
| 模型超时/丢失上下文 | `WAIT` | 内核继续回报、对账、原退出规则 | 工程裁决 |

依 [契约](contracts.md)，`WAIT / WATCH` 无意图，`PROPOSE` 仅买入，`REDUCE / EXIT` 仅卖出，均不表示成交。提案失效不等于在途订单取消；退出无可卖量时记录 `EXIT_BLOCKED`，不得虚构止损成交。

独立风控限制单股、题材、总风险、流动性与损失预算。确信度不决定仓位，“满仓”（P0028、P0188、P0205）仅为研究假设。退出优先于格局叙事，止损价不保证成交。

## 8. 验证与发布边界

规则台账保存来源、原意、解释、谓词、参数、失效、冲突及验证状态。P0613写有“还没回测”，其他“最稳、胜率最高”同样没有统计依据。当前 S01/S02 均为 `DESIGN_ONLY`。

各策略按时间切分训练、验证、冻结样本外窗口，保留失败实验和未交易候选。对照依次为：仅价格反弹、加入题材/状态、加入冻结预期、加入 LLM 催化解释。评价成本后收益、回撤、尾部损失、可成交率、信号覆盖、误判修复/切换、预测校准及参数敏感性。

禁用事后涨停原因、盘后龙虎榜、今日概念成分和最终龙头身份回填；数据与撮合限制见 [风控与验证](risk-and-evaluation.md)。agent可提出实验，不可自行发布策略、放宽风控或篡改旧预期。下一环境的晋级须通过数据时点、成交模型、样本外证据和工程检查。
