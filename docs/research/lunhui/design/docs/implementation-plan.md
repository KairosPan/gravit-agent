# 实施路线

本轮完成系统设计。下列内容为下一阶段开发任务，不表示已实现。默认先回放与 paper，无需券商凭证即可完成前四阶段。

## 建议目录

```text
apps/
  research-worker/       dsh profile 启动与任务生命周期
  workbench/             计划 证据 风险 订单 复盘工作台
packages/
  domain/                证据 预期 状态 意图与规则类型
  dsh-trading-research/   dsh 工具及角色 bundle
  data/                  数据接入 时间对齐 版本化快照
  features/              确定性特征与候选状态
  playbooks/             两个优先策略与研究分支
  risk/                  风险校验 原子预占 许可
  execution/             订单状态机 对账 适配器
  replay/                虚拟时钟 保守撮合 成本模型
  evaluation/            封存测试 消融 归因与报告
contracts/               可版本化的跨层契约
references/              原文与研究来源
```

这是从零规划的目录，不复制旧项目结构。先做模块化单体及独立 dsh worker；没有吞吐瓶颈证据前不引入 Kafka 或多个自治交易 agent。

## 分阶段交付

| 阶段 | 交付内容 | 验收条件 | 依赖 |
|---|---|---|---|
| M0 基础与版本 | 固定 dsh 精确版本、导出有效配置、2 个只读工具、1 个意图提交工具 | 实际 profile 能启动；禁用工具不存在；会话、取消和 schema 错误可追踪；额外上传配置已核查 | 选择模型访问方式；只有真实模型 smoke 才需要 key |
| M1 时点数据 | 证券主数据、公告、分钟行情、题材版本、虚拟时钟、数据质量报告 | 任何查询不能获得 as_of 之后数据；缺失历史公告时间显式降级；含退市/停牌样本 | 数据供应商与许可评估 |
| M2 策略回放 | 冻结预期、两个 playbook、WAIT、反证角色、可追溯决策卡 | 固定输入的特征和门槛可复现；同一 schema 的模型差异可审计；回放交易不偷看当前 bar 收盘 | M0、M1；策略参数只用训练集 |
| M3 模拟执行 | 账本、资金预占、风险许可、部分成交/撤单/UNKNOWN 状态机、保守撮合 | 风控与账本不变量全部通过；每个订单能回查到意图、许可、数据版本；重启不重复记账 | M2；完成故障注入 |
| M4 影子与 paper | 实时只读行情、冻结策略前瞻观察、日报与周报、运行监控 | 收益/回撤/成交率/成本/延迟/失败覆盖都达到事先签定门槛；配置漂移可检测 | M3；在线行情可用；不接实盘 |
| M5 实盘准备 | 券商仿真与专用账户适配、规则复核、程序化交易流程、权限隔离、人工急停 | 券商回查/撤单语义真实验证；责任人与限额确认；有限资金范围的独立批准 | 用户进一步授权与提供市场/券商/资金约束 |

M4 的最小观察跨度建议先设 60 个交易日，并且必须覆盖足够的策略触发事件和至少两类市场状态；这只是样本收集下限，不构成“达 60 天就上线”的条件。策略样本稀少、状态未覆盖或统计区间仍宽时继续收集。胜率目标不单独作为晋级门槛。

M1 的分钟线先支持状态与策略门槛研究。可以采用“已完成 bar 后最早下一 bar 才参与撮合”的保守研究回放，但必须标注未知的分钟内路径、成交仅为近似，不能宣称验证了短线成交能力。M3/M4 若要使用 2 秒盘口时效和 5 秒意图期限的执行配置，必须补齐足够频率、具有可信接收时点的 L1/逐笔数据；否则只保留研究信号，不产生 paper fill。研究用 bar 配置与盘口执行配置分别版本化，禁止把分钟样本伪装为实时盘口。

## 首批实现任务的顺序

1. 把本设计的 schema、策略谓词和风险不变量转成类型及契约校验。先让完全确定性的 WAIT 流程贯通。
2. 写 dsh 最小集成实验：使用冻结合成数据，模型通过注册工具提交一个可校验的研究决策；记录实际 API/provider、preset 和 bundle 版本。实验只证明接入，不证明交易能力。
3. 实现行情快照和证券规则适配器。先用完整交易日的确定性回放验证“现在能看到什么”，再加模型分析。
4. 实现保守撮合、订单账本和故障恢复。没有执行真实性之前，不展示策略累计收益曲线作为有效结果。
5. 让两个策略在相同数据、成本和风险预算下与规则基线比较。模型若只增加费用或解释长度，允许保留规则策略而取消该模型步骤。
6. 完成只读工作台：能点击任何决策查看冻结预期、证据、风控原因和未成交原因，再进入实时 paper。

## 需用户在对应阶段给出的参数

| 决策 | 当前默认 | 最晚确定阶段 |
|---|---|---|
| 市场与品种 | 沪深主板非风险警示普通 A 股 | M1；扩展品种需规则与撮合重验 |
| 初始模拟资金 | 仅作为配置，不在本设计中假定实际资金 | M2 |
| 风险承受范围 | 采用风控章节的保守 paper 初值 | M2 前冻结；实盘单独确认 |
| 行情源与粒度 | 供应商中立，分钟级先行，不假定已有 L2 | M1 |
| 模型与预算 | 通过 dsh provider 配置，记录版本和实际成本 | M0 |
| 实盘券商及权限 | 未选择，未接通 | M5 |

这些未知项不阻塞当前架构设计，但会决定哪些策略有资格进入有效回测。不得用占位数据完成一轮演示后声称策略已经通过验证。
