# 轮回智能交易 Agent 设计

以《轮回》的周期、情绪、题材、龙头和预期差框架为策略研究起点，以 [DeepSeek Harness（dsh）](https://www.deepseek.com/en/harness/) 为 agent 运行底座，设计一个能够解释交易假设、检验证据、遵守交易约束并持续复盘的 A 股交易系统。

核心决策是：**dsh 负责提出和检验交易假设；独立交易内核决定是否允许交易，并维护资金、持仓和订单的唯一事实记录。** 模型可以选择空仓，不能修改风控或把自己判定的“龙头”当作风控豁免。

本分支 `codex/lunhui-agent-design` 从无父提交的空分支开始，包含新设计、独立前端和用户提供的原始资料。未读取、复用或迁移既有业务代码与旧设计。

## 首版范围

沪深主板、非风险警示的普通 A 股，做多、无杠杆；仅连续竞价限价单。先实现历史回放和模拟交易，竞价作为观测输入。连板、情绪和题材是候选机会的研究依据；涨停排队、竞价抢单、微秒级交易不在首版执行范围内。

优先验证“主线核心分歧后的修复”和“旧题材退潮后的新方向确认”两类假设。容量模式在原文中注明移至其他文档，因此不补写为完整策略。冰点反核、一字板和弱转强竞价先保留为研究分支。

## 当前交付状态

已提供可评审的设计包，以及 [独立研究工作台](frontend/README.md)。使用 Node.js 22+，运行 `cd frontend && npm ci && npm run dev`，在 [本机预览](http://127.0.0.1:4173) 查看真实行情和按需运行的单轮研究；端口占用时可设置 `PORT`。

**已接入腾讯公开报价、60 日日 K 和官方 DeepSeek Harness `0.2.0-rc.2`，并完成真实模型调用。** 模型读取冻结的行情与策略证据，输出带引用、反证和缺口的 WATCH/WAIT 报告。报告、任务状态和运行元数据保存在本机；刷新页面不会重跑模型。

目前是只读研究入口，未实现券商连接、实际回测或完整交易内核。缺少分钟数据、冻结题材和催化证据时，S01/S02 保持不可评估。真实研究和合成账户演示独立切换；结构和引用校验不等于自然语言事实核验，也没有收益验证。
