# The China Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A China tab at the end of the Markets tab row, listing the day's top 20 A shares by turnover or by move from Tencent's ranking, and an A-share page with twelve facts and a price history, all on the face's own wire.

**Architecture:** Three new server modules behind the `/data` fence: the A-share session (`cn-session.ts`), the ranking route (`cn-rank.ts`) and the history route (`cn-candles.ts`). The quote wire (`quote-snapshots.ts`, `quotes.ts`) gains the page's facts and the session. On the client, the Markets slice gains a `rank` read, the pure views (`host/market-view.js`) gain the China rows, the state words and the A-share page's view, the host (`host/markets.js`) polls the ranking while China is on screen and reads an A-share page's history, and the renderers draw the China table and the new page.

**Tech Stack:** Node 22 + TypeScript through tsx (`face/src`), vanilla ES modules in the browser (`face/client/js`), `node --test` (`face/tests`, `face/tests/client`).

**Spec:** `docs/superpowers/specs/2026-10-31-china-tab-design.md` (approved 2026-10-31, commit 471cf709). Read it before Task 1. §6 holds the measured Tencent endpoints and fields.

## Global Constraints

- China is the last tab of the row, after Predictions and before Watching when Watching shows. Markets still opens on All.
- One ranking table: the top 20 (`RANK_ROWS = 20`). Most traded is by turnover; Biggest moves is by the size of the day's change, gainers and losers together.
- No indices, no boards, no breadth, no A-share Buy or Sell.
- The client never asks the Account for `explore?tab=china`.
- Nothing reads for China while Markets is off screen, the tab is hidden or another tab is selected.
- Neither iFinD nor Eastmoney is called. Nothing under `face/src` or `face/client` imports from `face/plugins/`.
- Every new route sits behind `isTrustedDataRequest` (`face/src/http.ts`): 403 with `FORBIDDEN`, 405 for any method but GET, `no-store` JSON, nothing logged.
- Product copy is English; A-share names stay as Tencent writes them.
- A-share times are Beijing time (`Asia/Shanghai`) and always say `Beijing` (`Closed · 10-30 15:00 Beijing`). No A-share surface prints `Stale` or a New York time.
- Yuan amounts use `yuan()` from `face/client/js/render/lunhui/block.js` (`¥216.10亿`, `¥1.74万亿`, `¥5707.52万`).
- Tencent hosts and paths are exactly those of spec §6. No credential, no extra header.
- Commit messages carry no backticks, `$(` or parentheses (shell traps). Commit with `-m` plain words, or `-F <file>`.
- Work in worktree `.claude/worktrees/china-tab` on branch `feat/china-tab`, cut from local main 471cf709. Run `cd face && npm ci` there first. Never `git switch` in the primary checkout. Never push.

## Review Focus

1. **Tencent answers the ranking with a throttle page, HTML or `code != 0`.** The route answers 503 with its fixed body and caches nothing. The table keeps its last rows under a muted line. Tested in Task 3 (route) and Task 8 (screen).
2. **A share listed this week has fewer than five sessions of minutes.** 5D draws the sessions that exist, and 1D on its first day still draws. Tested in Task 4 and Task 8.
3. **A deep link to an A-share page that no read lists** (a reload on `#/markets/cn:300502`). The title comes from the quote's `name` once it lands, and shows the code before that. Tested in Task 6.
4. **The sort switched while the other sort's read is still in the air.** Only the answer for the sort now in effect lands, and the table shows no rows in the wrong order meanwhile. Tested in Task 6 (rows hidden) and Task 7 (stale answer dropped).
5. **A loss-making share's negative P/E** (Tencent field 39 below zero). It is kept and drawn with U+2212 (`−12.50`), never dropped as invalid. Tested in Task 2 and Task 8.

const lunch = weekday && minute >= 690 && minute < 780;          // 11:30–13:00
if (stat === "open") return lunch ? "midday" : "trading";
if (stat === "closed") return lunch && lastSession === today ? "midday" : "closed";
if (!weekday) return "closed";
if (lunch) return "midday";
return (minute >= 570 && minute < 690) || (minute >= 780 && minute < 900) ? "trading" : "closed";

- [ ] **Step 3: Implement `face/src/cn-rank.ts` and register it**

- **The request.** URL: `https://proxy.finance.qq.com/cgi/cgi-bin/rank/hs/getBoardRankList?_appver=11.17.0&board_code=aStock&sort_type=<t>&direct=<d>&offset=0&count=20`. Fetch with `redirect: "error"`, read the body bounded at 256 KiB, and time out at `QUOTE_TIMEOUT_MS`.
- **Rows.**
  - A row's code must match `/^(sh|sz|bj)(\d{6})$/` and its name must be non-empty.
  - `zxj` gives the price, positive or null; `zdf` gives `change_pct`, finite or null; `turnover` is ×10,000 through `Math.round`.
  - `total` must be an integer of at least 0, and `rank_list` an array. Anything else throws.
- **Movers.** `mergeMovers` concatenates, keeps the first copy of an id, sorts by `|change_pct|` descending (nulls last), breaks ties by turnover descending, and keeps `limit` (default `RANK_ROWS`).
- **Each sort.** `createCnRank` runs `readCnSession` beside the ranking calls. It keeps a cache entry `{ at, answer }` per sort and one flight per sort.
- **The route.** Shaped like `registerSymbolSearchRoute` in `symbol-search.ts`.
- **main.ts.** `const disposeRank = registerCnRankRoute(booted.ctx.webServer, createCnRank());`, then `disposeRank()` in `disposeData`.
- **DEVELOPMENT.md** §4.4 gains the route's row, worded like the `/data/symbols/search` row.
