# News Scout

从一句主题线索查找近期新闻，追溯原始来源、核对日期并按事件去重。

先在 face 的 Discover 里打开 News Scout 的「Gravit 可用」开关。之后请 Gravit 为它开一个任务
（工作目录是 `bots/news-scout/journal`），或开一个辩论任务，把它作为只读成员请进来。

示例：

- 有博主说液冷需要关注，帮我查一下最近几天有哪些相关新闻。
- 查液冷过去 3 天的新进展，优先找公司公告和客户项目消息。
- 核查这篇帖子中的订单说法，找原始出处，区分事实与推测。

默认检索最近 7 个自然日（含今天），中英文搜索，中文简报。输出检索窗口、
事件与发布日期、关键事实、主题相关性、证据状态和原文链接；通常最多 5–8 个
独立事件。没有足够可核验的新消息就如实说明，较旧材料单独标作背景。

每次请求执行一次检索，后续追问“最新”时重新搜索。此 bot 本身没有后台监控任务。
联网依赖当前 dsh tree 提供的 `web_search`；若工具或网络不可用，明确报告未完成检索。

由 face 的 `createBot` 创建。`SOUL.md` 是职责来源，`agent.cordis.yml` 是生成的运行配置；
后续通过 face 保存 persona，使两者同步。保留模板的工具权限，沿用默认模型。
`skills/` 预留给操作员添加检索技能；`journal/` 仅供 bot 在 home 会话中记录检索笔记。
